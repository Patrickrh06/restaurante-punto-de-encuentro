# 🍲 Restaurante "El Punto de Encuentro" - Menú Web Interactivo

Este es un proyecto web interactivo diseñado para un restaurante de comida típica cochabambina. Permite a los usuarios seleccionar platos, agregar bebidas al carrito de compras y enviar su pedido formateado directamente al número oficial de WhatsApp del establecimiento.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica de la página web (Navbar, secciones, modales y formularios).
- **CSS3:** Maquetación responsiva (*Mobile-First*), estilos visuales, paleta de colores de Cochabamba e interfaz limpia.
- **JavaScript (Vanilla ES6):** Lógica interactiva de filtrado de productos, administración del estado del carrito, cálculo de totales y generación de mensajes codificados para la API de WhatsApp.

---

## 📂 Estructura del Proyecto

- `index.html`: Estructura principal y maquetación de la aplicación.
- `styles.css`: Estilos visuales, adaptabilidad móvil y formato de tarjetas/modal.
- `script.js`: Base de datos local JSON en memoria, manipulaciones del DOM y lógica del pedido.
- `README.md`: Documentación del sistema.

---

## 🚀 Cómo Ejecutar el Proyecto en VS Code

1. Abre **Visual Studio Code**.
2. Ve a `Archivo > Abrir Carpeta...` y selecciona la carpeta del proyecto.
3. Asegúrate de instalar la extensión **Live Server** en VS Code.
4. Haz clic derecho sobre el archivo `index.html` y selecciona **Open with Live Server**.
5. ¡Listo! Se abrirá la página web en tu navegador predeterminado.
